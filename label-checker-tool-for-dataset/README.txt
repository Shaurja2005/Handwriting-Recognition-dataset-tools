Batch JSON Label Checker

What it does:
- Upload multiple .json files.
- Enter a target label value.
- It checks each file's top-level "label" field.
- It lists file names that do not match.

How to run:
1. Open: index.html in any modern browser.
2. Enter the target label (for example: +).
3. Select multiple JSON files.
4. Click "Check Files".

Notes:
- If a file has invalid JSON, it is listed as mismatch.
- Comparison is exact and case-sensitive.
