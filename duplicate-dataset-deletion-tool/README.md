# Duplicate Dataset Deletion Tool

This tool helps you identify and remove duplicate entries from your handwriting recognition dataset. It is designed to clean up JSON or CSV files containing dataset samples, ensuring that each entry is unique.

## Features

- Detects duplicate entries in dataset files
- Removes duplicates and saves a cleaned version
- Supports JSON and CSV formats

## Usage

1. Place your dataset file (e.g., `sample-dataset.json` or `data.csv`) in the same directory as `tool.py`.
2. Run the script using Python:

```
python tool.py
```

3. Follow the prompts to select your dataset file and review the results.

## Requirements

- Python 3.x

## Customization

You can modify the script to handle different dataset formats or add additional cleaning steps as needed.
