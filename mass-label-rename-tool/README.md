# Mass Label Rename Tool

This tool helps you rename multiple labels in your dataset files efficiently.

## Features

- Batch rename labels in dataset files
- Supports various file formats (customize as needed)
- Simple command-line interface

## Usage

1. Place your dataset files in the appropriate directory.
2. Run the tool using Python:

   ```bash
   python tool.py
   ```

3. Follow the prompts to specify which labels to rename and their new names.

## Requirements

- Python 3.x

## Customization

- Edit `tool.py` to add support for additional file formats or custom renaming logic.
